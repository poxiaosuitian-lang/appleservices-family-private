# 隐私邮箱自动转发

在订阅购买完成、订阅记录与付费容量均核验通过后，排队检查隐私邮箱的默认转发目标。先返回购买成功，再执行网页认证与转发，避免认证超时影响购买结果。导入账号和登录时不触发；这一步不会购买订阅或自动创建隐私地址。

尚无隐私地址时延后设置。首次创建地址成功（包括创建响应异常但回读确认成功）后，自动从 Apple 返回的已验证转发候选中选择唯一的 `@icloud.com` 邮箱，排除隐私地址本身。读取地址时也会补办未完成的初始化。无候选或多个候选时不猜测，面板提示手动选择。

设置后核对默认目标和所有启用地址的实际转发目标。任务按账号保存在运行状态目录 `hme-forward.json`，不包含密码或令牌，不提交仓库。发送前保存意图；超时或结果不明时只回读核验，不重复创建地址或重放设置。已完成后不会覆盖后续手动选择。

转发失败不抹掉已创建地址，面板保留地址列表并提示处理。自动化测试覆盖首次创建、账号隔离、目标歧义、丢失响应与重复执行；不发送测试邮件。
