# 安全提示问题自动验证

面板“概览”或“iCloud+”中的“安全提示问题”卡片提供填写、加密保存和清除入口。新账号导入后的邮箱任务遇到 Apple 密保挑战，会读取 Apple 当前返回的问题，显示在当前账号卡片中。也可以点击“读取验证问题”主动检查。输入答案后点击“加密保存并继续验证”，即可继续原来的邮箱检查/自动创建任务。

保存仅针对当前账号。题目来自 Apple，不按朋友、工作等关键词模糊猜测，不按问题显示顺序套用答案；提交时按 Apple 的 `id` 匹配，并携带本次挑战的 `question`、`number`。Apple 只返回本次挑战的题目，后续出现尚未填写的题目时仍需补充一次。

答案使用 Windows 当前用户的 DPAPI 加密，保存为账号独立目录中的 `security-answers.dpapi`，加密附加绑定 Apple ID 与已验证登录 ADSID。换账号、复制到另一账号目录或密文损坏时拒绝读取。页面只接收问题和“已保存”状态，不回显答案；答案不写浏览器存储、运行日志或 Git。清除答案不会删除设备身份；清除整个登录会话也会删除密保凭据。

已接入的调用方是 iCloud 主邮箱、隐藏邮件地址和 Apple 账户管理网页认证。它们在 Apple 返回 `sa` 密保挑战时共享同一账号答案库。此功能不会代替短信验证码、双重认证、条款接受、支付确认等不同类型的验证。

协议依据为 Apple 公开 [SA 网页模块](https://appleid.cdn-apple.com/appleauth/static/module-assets/sa-43872c870057a6ae7d34.js)及其 [认证状态处理模块](https://appleid.cdn-apple.com/appleauth/static/module-assets/home-c702d19e62c250fcaaa7.js)（2026-11-11 核对）：从 `/appleauth/auth` 返回 HTML 的 `boot_args.direct.twoSV.securityQuestions.questions` 读取题目，向 `/appleauth/auth/verify/questions` 提交 `questions` 数组。200、204、250 表示本步完成，可继续信任会话并由业务接口核验；409、412 表示仍需继续认证/修复，不误报为答案错误。

缺少答案时不提交；答案提交只执行一次。Apple 拒绝、要求进一步验证或网络结果不明确时，加密保存对应暂停原因，重启也不会连续重复提交。400/401 拒绝需修改答案；额外验证完成后可点击“读取验证问题”显式继续一次。保存成功不等于 Apple 已接受答案，也不等于邮箱已经创建；面板分别显示密保和邮箱状态。

测试覆盖 DPAPI 隔离、篡改检测、清除、重启后的拒绝标志、未知问题、题目乱序、缺少答案、敏感响应屏蔽、浏览器输入清除与保存后续接。所有测试使用合成账号/答案。
