# 订阅后的应用专用密码

每个账号的 iCloud+ 购买结果和付费容量核验成功后，后台自动配置并记录该账号的应用专用密码。已经订阅的账号在成功登录后也检查一次；存在加密记录时直接复用。页面轮询和十分钟续登录不会反复生成密码。

在“iCloud+ 开通与方案”卡片中查看状态。成功后显示“应用专用密码：已加密保存”，停止后台仍可查看。已在线且付费容量已核验的账号可以点击“配置应用专用密码”主动继续；配置正在提交时暂不可重复操作。

Apple 要求额外验证、配置失败或结果尚未确认时，卡片保留原因并提供手动保存入口。前往 [Apple 账户](https://account.apple.com/) 完成验证，在“登录和安全”中生成应用专用密码，再回到当前账号卡片填写并点击“加密保存”。输入框为密码类型，提交前清空；切换账号、重新连接或状态已完成也会清空，不写入浏览器存储。

Apple 要求账户开启双重认证才能生成应用专用密码。更改或重置 Apple 账户主密码会撤销现有应用专用密码；本地“已加密保存”仅说明已记录，并不保证 Apple 尚未撤销。手动生成路径和撤销规则见 [Apple 官方说明](https://support.apple.com/zh-cn/102654)。

记录保存在账号独立目录的 `app-password.dpapi`，使用 Windows 当前用户的 DPAPI 加密，并绑定 Apple ID 和 GSA DSID。`app-password-status.json` 只保存公开进度。面板和操作响应只返回 `state`、`message`、`label`、`updated_at`，不返回密码；密码不写入运行日志或 Git。

`app-password-ensure` 负责配置或复用，`app-password-save` 接收用户在 Apple 官方页面生成的密码并加密保存。创建请求已提交但结果不明时保留记录，重启后显示待确认，不自动重新生成。额外验证和失败也不会循环重试。

离线页面测试 `tools/test-app-password-ui.cjs` 使用合成账号和密码，覆盖未订阅、配置中、额外验证、失败、待确认、已保存及后台停止状态，并检查提交前清空、账号/会话隔离、浏览器存储无密码以及窄屏布局。

2026-11-14 实机验收：已订阅账号通过 Apple 账户管理会话生成应用专用密码，Apple 列表回读确认新增记录，本机 DPAPI 保存成功。再次配置成功解密并复用同一文件，未重复生成。未进行 IMAP 收信验收。当前 Apple 在无记录时返回 HTTP 200 空对象，协议已兼容此形态；生成接口返回的 16 位字母在加密保存前统一为四组格式。
